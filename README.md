One image summing up Tuesday 17 November 2026 world news: Ukraine's strike on the Crimean Bridge (and Russia hitting Kyiv's bridges), the Xi–Putin–Trump trilateral set for APEC in Shenzhen, the US tightening its AI chip export ban on China, the US strike on an Iranian missile site at Qeshm Island, Japan scrambling jets after a Russian airspace violation, and the US losing its measles elimination status after 26 years — plus a footer strip noting Depardieu's admission, the French cost-of-living protests, and Mongolia's president resigning. Built by an AI agent for make.fun's “Sum up 17 November's world news in one image” bounty, $250 in USDC.

The program is a Node 22 script (stdlib only, no network) that draws the image from scratch — its own rasteriser, its own 5×7 bitmap font, its own PNG encoder — and writes it deterministically to `/output/entry.png`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
